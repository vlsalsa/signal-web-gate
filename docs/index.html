Beginner guide · Mac or Windows

Signal in your browser, hosted on your own computer

This guide walks you through every click. When you finish, you can open Signal from any web browser, for example on a work laptop, at an address like signal.example.com. Only you can get in.

Pick your computer type with the Mac / Windows buttons at the top. Tick each step when it's done. Your ticks are saved in this browser only, so you can stop and come back later.

Before you start

  • Time: about 1 to 2 hours the first time. Most of it is waiting for downloads.
  • A computer that stays on: a Mac or a Windows 10/11 PC with at least 8 GB of memory and 10 GB of free space. Signal only works while this computer is on and awake.
  • Your phone with Signal already set up. You'll link it at the end, like linking Signal Desktop.
  • An email address you can check. You'll get a 6-digit sign-in code there each time you sign in.
  • A web address (domain) on Cloudflare. If you don't have one, step 3 shows how to buy one (about $10 a year). Everything else is free.
  • Permission to install apps on the computer. You'll need your computer password.
Good to knowYour Signal messages will be stored on this computer. Anyone who can sign in to this computer, or who has its backups, could read them. Use a computer only you use, with a password and disk encryption (FileVault on Mac, BitLocker or Device Encryption on Windows).
How does this work? (optional reading)

Three small programs run inside Docker, an app that runs software in sealed boxes called containers:

  1. Signal, the normal Signal Desktop app, shown as a web page.
  2. The gate, a password page that only lets you through.
  3. The tunnel, made by Cloudflare. It connects out to Cloudflare, so you don't open anything on your home router.

When you visit your address, Cloudflare first emails you a code (this is Cloudflare Access). Then the gate asks for your password. Only then do you see Signal.

This stays in this browser. Don't type passwords or tokens into this page.

Step 1 of 11

Install Docker Desktop

Done

Docker Desktop is the free app that runs the three programs. It's free for personal use and small businesses.

On a Mac
  1. Find out which chip your Mac has: click the Apple menu (the apple logo at the top left), then About This Mac. Look for Chip (Apple M1, M2, M3…) or Processor (Intel).
  2. Go to docker.com/products/docker-desktop and choose Download for Mac – Apple Silicon or – Intel Chip to match.
  3. Open the downloaded Docker.dmg and drag the Docker whale into the Applications folder.
  4. Open Docker from Applications. Accept the terms. Choose Use recommended settings and type your Mac password if asked.
  5. Signing in to Docker is optional. You can choose Skip or Continue without signing in.
  6. Apple-chip Macs only: open Docker's Settings (gear icon) → General, and make sure Use Rosetta for x86_64/amd64 emulation on Apple Silicon is turned on. Click Apply if you changed it.
On Windows
  1. Go to docker.com/products/docker-desktop and choose Download for Windows – AMD64. (ARM-based Windows PCs aren't supported by this guide.)
  2. Run Docker Desktop Installer.exe. Leave Use WSL 2 instead of Hyper-V ticked, then click OK.
  3. When it finishes, click Close and restart (or restart the PC yourself).
  4. After the restart, Docker Desktop opens. Accept the terms. Signing in to Docker is optional; you can skip it.
  5. If Docker says WSL needs an update, follow its button, or see “Stuck?” below.

Wait until the bottom-left corner of the Docker window says Engine running with a green dot.

Open the command window

A few steps ask you to paste a command. Here's how to open the window for that:

On a Mac

Press ⌘ Command + Space, type Terminal, and press Return. To run a command, click a Copy button on this page, click in Terminal, press ⌘ Command + V, then press Return.

On Windows

Click Start, type PowerShell, and open Windows PowerShell. You don't need “Run as administrator”. To run a command, click a Copy button on this page, right-click inside PowerShell (or press Ctrl + V), then press Enter.

Now check that Docker works. Paste this and run it:

docker run --rm hello-world
What you should seeAfter a few seconds, a message that includes Hello from Docker!
Stuck? Common fixes
  • “command not found” or “docker is not recognized”: close the Terminal/PowerShell window, open a new one, and try again. Docker Desktop must have been opened at least once.
  • “Cannot connect to the Docker daemon” or “error during connect”: Docker Desktop isn't running yet. Open it and wait for Engine running.
  • “WSL needs updating” or “WSL 2 installation is incomplete”: open PowerShell, run wsl --update, and restart the PC.
  • “Virtualization support not detected”: virtualization is turned off in the PC's firmware (BIOS/UEFI). Search the web for your PC model plus “enable virtualization”. The setting is usually called Intel VT-x, Intel Virtualization Technology or AMD SVM.
  • “Docker.app is damaged” or it won't open: you probably downloaded the version for the other chip. Delete it from Applications and download the other one.

Step 2 of 11

Download this project

Done

These are the files the setup helper uses. You'll put them in a folder called signal-web-gate in your home folder. Don't put them in a folder that syncs to iCloud, OneDrive or Dropbox: your secret keys will be stored there.

Option A (easiest): download a ZIP

  1. Click this link to download it: signal-web-gate-main.zip.
  2. Then paste this command, which unzips it into your home folder and opens the folder:
On a Mac (Terminal) 
cd ~/Downloads && { [ -d signal-web-gate-main ] || unzip -q signal-web-gate-main.zip; } && mv signal-web-gate-main ~/signal-web-gate && cd ~/signal-web-gate && ls

Safari often unzips downloads by itself. The command handles that.

On Windows (PowerShell) 
Unblock-File "$HOME\Downloads\signal-web-gate-main.zip"
Expand-Archive "$HOME\Downloads\signal-web-gate-main.zip" -DestinationPath $HOME
Rename-Item "$HOME\signal-web-gate-main" signal-web-gate
cd "$HOME\signal-web-gate"
ls

Unblock-File tells Windows you trust this download, so the setup helper can run later.

Option B: use Git instead (makes updating easier)
On a Mac

Run this. If your Mac offers to install the “command line developer tools”, click Install, wait for it to finish, then run the command again.

git clone https://github.com/vlsalsa/signal-web-gate.git ~/signal-web-gate && cd ~/signal-web-gate && ls
On Windows

Install Git (accept any prompts), then close PowerShell and open a new window:

winget install --id Git.Git -e

Then download the project:

git clone https://github.com/vlsalsa/signal-web-gate.git "$HOME\signal-web-gate"
cd "$HOME\signal-web-gate"
ls
What you should seeA list of names that includes docker-compose.yml, scripts, setup.commandsetup.bat, and README.md.
Stuck? Common fixes
  • “No such file” or “cannot find path”: the ZIP isn't in your Downloads folder, or it has a different name, such as signal-web-gate-main (1).zip. Rename it to signal-web-gate-main.zip and try again.
  • “already exists”: you've done this before. Either use the existing signal-web-gate folder, or rename the old one first.
  • Every later command assumes you're inside the folder. If you open a new window, first run cd ~/signal-web-gatecd "$HOME\signal-web-gate".

Step 3 of 11

Get a domain on Cloudflare

Done

Your Signal address will be a sub-address of a domain you own, like signal.yourname.com. Cloudflare must manage that domain.

  1. Create a free Cloudflare account at dash.cloudflare.com/sign-up and confirm your email.
  2. Then pick one:
    • I don't have a domain: in the Cloudflare dashboard, open Domain Registration → Register Domains, search for a name, and buy it. Cloudflare charges cost price, about $10 a year for a .com. It's ready in a few minutes.
    • I already have a domain elsewhere (GoDaddy, Namecheap, Google/Squarespace…): in Cloudflare, choose Add a domain (it may say Onboard a domain), type it, and pick the Free plan. Cloudflare shows two nameservers. Sign in at your current domain company and replace its nameservers with those two. This can take from minutes to a day.
If the domain already runs a website or emailMoving the nameservers moves all of its settings. Cloudflare tries to copy your existing records. Check that your email and website still work, or use a new, spare domain.
What you should seeOn the Cloudflare dashboard home page, your domain is listed with the status Active.
Stuck? Common fixes
  • Still “Pending” after a day: the nameservers at your old domain company don't exactly match the two Cloudflare showed. Copy them again, and remove any extra ones.
  • Decide on the full address now, for example signal.yourname.com, and type it into the box near the top of this page.

Step 4 of 11

Turn on Cloudflare Zero Trust

Done

Zero Trust is the free Cloudflare feature that emails you a sign-in code before anyone can even see your page.

  1. In the Cloudflare dashboard's left menu, click Zero Trust.
  2. The first time, it asks you to choose a team name. Pick something simple, like yourname-home. Write it down. Your sign-in page will be yourname-home.cloudflareaccess.com.
  3. Choose the Free plan. Cloudflare may ask for a payment card even for the free plan; the free plan costs $0.
  4. Turn on email codes: go to Integrations → Identity providers → Add new identity provider (or Add new) → One-time PIN. Save it.
What you should seeOne-time PIN is listed under your identity providers, and you've written down your team name.
Stuck? Common fixes
  • Can't find a menu item: Cloudflare renames menus from time to time. Use the search box at the top of the dashboard, and type “Identity providers”.
  • Forgot your team name: it's under Zero Trust Settings (look for Team name and domain). The part before .cloudflareaccess.com is the team name.

Step 5 of 11

Lock the address with Cloudflare Access

Done

This tells Cloudflare: “only these email addresses may open signal.example.com.” We do this before the address goes live, so it is never open to the public.

  1. In Zero Trust, go to Access controls → Applications → Create new application (or Add an application).
  2. Choose Self-hosted and private (older screens say Self-hosted).
  3. Name it Signal.
  4. Click Add public hostname. For Subdomain type signal, and for Domain pick your domain. Together they make signal.example.com.
  5. Under Access policies, choose Create new policy:
    • Policy name: Only me
    • Action: Allow
    • Add an Include rule. Selector: Emails. Value: your email address. Add others only if they should get in too.
    Save the policy. If it opened in a new tab, go back to the application and select Only me.
  6. Under Login methods (or Authentication), make sure One-time PIN is ticked.
  7. Set Session duration to how often you want to enter an emailed code, for example 24 hours.
  8. Click through to the end and click Create (or Save).

Copy two things for later

  1. The AUD tag. Open the new Signal application again (click its name or Edit/Configure), find Application Audience (AUD) Tag (often under Additional settings or Overview), and copy it. It's a long string of letters and numbers.
  2. Your team name from step 4.

Paste them into a note for now. They aren't passwords, but there's no need to share them.

What you should seeA Signal application in the list for signal.example.com, plus your AUD tag and team name saved in a note.
Stuck? Common fixes
  • Your domain isn't in the Domain list: it isn't Active yet (step 3), or it's in a different Cloudflare account.
  • Only use the email addresses you trust. Don't choose “Everyone”, or a whole domain like @gmail.com.

Step 6 of 11

Create the Cloudflare Tunnel

Done

The tunnel is how Cloudflare reaches your computer without opening anything on your home router.

  1. Go to Networking → Tunnels in the main Cloudflare dashboard (inside Zero Trust it's Networks → Connectors or Tunnels). Click Create a tunnel.
  2. If asked for a type, choose Cloudflared. Name it, for example signal-home, and save.
  3. Cloudflare shows install instructions. Choose Docker as the environment. You'll see a command containing --token eyJ….
  4. Copy that whole command, but don't run it. The setup helper only needs the token inside it, and it picks the token out for you. Keep it somewhere private for a few minutes.
  5. Click Next or Continue to add a route. Choose Published application (older screens say Public hostname):
    • Subdomain: signal. Domain: your domain. Leave Path empty.
    • Service: type http://signal-gate:8080. If there are two boxes, choose HTTP as the type and type signal-gate:8080 as the URL.
    Save the route.
The token is a secretAnyone with it can run your tunnel. Don't email it, post it, or put it in a chat. If it leaks, delete the tunnel in Cloudflare and make a new one.
What you should seeA tunnel in the list called signal-home, with a route for signal.example.com. It's fine that it says Inactive or Down: it turns Healthy after step 7.
Stuck? Common fixes
  • It won't let me continue until the tunnel connects: do step 7 now, then come back here and add the route.
  • “A DNS record already exists”: an old record uses the name signal. In your domain's DNS → Records, delete the old signal record, then save the route again.
  • Lost the token: open the tunnel, click Edit or Configure, and the install command with the token is shown again.

Step 7 of 11

Run the setup helper

Done

The helper asks a few questions, creates your secret keys, saves your password safely (only as a scrambled “hash”), and starts everything.

Make sure Docker Desktop says Engine running. Then:

On a Mac (Terminal) 
cd ~/signal-web-gate && bash scripts/setup.sh

You can also double-click setup.command in the folder. If macOS says it can't check the file, use the Terminal command above instead.

On Windows (PowerShell) 
cd "$HOME\signal-web-gate"
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1

You can also double-click setup.bat in the folder. If a blue “Windows protected your PC” box appears, click More info → Run anyway, or use the command above.

The questions it asks

QuestionWhat to type
Your Signal web addresssignal.example.com (from step 5)
Your Cloudflare team nameThe team name from step 4, e.g. yourname-home
Application Audience (AUD) tagPaste the AUD tag from step 5
Email address(es) allowed inThe same email(s) as your Access policy
Time zonePress ReturnEnter to accept the suggestion
Tunnel tokenPaste the whole command from step 6. Nothing appears while you paste; that's normal.Only * symbols appear.
New gate password (twice)A new password, 12 characters or longer, that you don't use anywhere else. Save it in a password manager.

Then it builds and downloads everything. The first time this takes 5 to 15 minutes and downloads about 2 GB.

What you should seeGreen OK lines, including Password gate is healthy and Cloudflare Tunnel is connected, and finally All set. In Cloudflare, the tunnel now shows Healthy.
Stuck? Common fixes
  • Any question rejects your answer: it tells you why and asks again. Copy the value from Cloudflare again; don't include spaces.
  • “The tunnel hasn't connected yet”: wait a minute and check the tunnel in Cloudflare. If it stays down, the token was wrong. Run the helper again, answer n to “Keep it?” for the token, and paste it again.
  • The build failed: usually the internet dropped. Run the helper again; it picks up where it left off.
  • Made a typo in an answer: run the helper again and answer n to “Keep these settings?”.
  • “Permission denied” on setup.command: use the Terminal command above; it doesn't need special permissions.
  • “running scripts is disabled on this system”: use the exact command above. It includes -ExecutionPolicy Bypass, which allows only this one run.
  • Running the helper again is always safe. It keeps what's already done unless you say otherwise.

Step 8 of 11

Open your Signal address

Done
  1. In any browser, go to https://signal.example.com/.
  2. A Cloudflare sign-in page appears. Type your email and click Send me a code.
  3. Check your email for a message from noreply@notify.cloudflare.com. Type the 6-digit code. It expires after 10 minutes.
  4. Next, a dark page titled Signal asks for a password. Type the gate password from step 7.
  5. Signal Desktop starts inside the page. The first time, this can take a minute.
What you should seeSignal's “link your phone” screen with a big QR code.
Stuck? Common fixes
  • No code email: check spam. Cloudflare only sends it to addresses in your Access policy, but it always says a code was sent. Check the spelling of the email in step 5.
  • “That account does not have access”: the email isn't in the Access policy, or the code was already used. Request a new code.
  • The page doesn't load, or shows a Cloudflare error 1033 or 502: the tunnel or Docker isn't running on your computer. Open Docker Desktop and check that the three containers are running (see everyday use).
  • “Forbidden” or “Unauthorized” after the code: the email you signed in with isn't in the helper's allowed list, or the AUD tag or team name is wrong. Run the helper again and answer n to “Keep these settings?”.
  • Wrong password too many times: the gate locks for 15 minutes after 5 wrong tries. Wait, or set a new password.
  • Safari offers to save a password: that's harmless; it isn't a second login.
  • Black screen: see step 11.

Step 9 of 11

Link your phone

Done

This works just like linking Signal on a regular computer.

  1. Open Signal on your phone.
  2. iPhone: tap your profile picture (top left) → Settings → Linked Devices → Link New Device.
    Android: tap your profile picture (or the ⋮ menu) → Settings → Linked devices → Link a new device (or the + button).
  3. Point the phone's camera at the QR code in the browser.
  4. If asked, choose whether to transfer recent message history, then give the device a name.
What you should seeYour chats appear in the browser. New messages show up in both places.
Stuck? Common fixes
  • The QR code expired: wait for a new one to appear, or reload the page, then scan again.
  • The phone won't scan: make the browser window bigger, or zoom in with ⌘ + +Ctrl + +.

Step 10 of 11

Keep it running

Done

Signal in the browser works only while this computer is on, awake, and running Docker Desktop. Docker restarts the three programs by itself.

  1. In Docker Desktop, open Settings (gear icon) → General, and turn on Start Docker Desktop when you sign in to your computer. Click Apply.
  2. Stop the Mac from sleeping: System Settings → Energy (on laptops: Battery → Options) → turn on Prevent automatic sleeping when the display is off (on laptops, choose the “when on power adapter” option). Keep a laptop plugged in.
  3. Stop the PC from sleeping: Settings → System → Power & battery (Windows 10: Power & sleep) → Screen and sleep → set “When plugged in, put my device to sleep after” to Never. Keep a laptop plugged in.
  4. After a restart or an update, sign in to the computer once, so Docker Desktop can start.
What you should seeAfter restarting your computer and signing in, your Signal address works again within a few minutes, without you doing anything.

Step 11 of 11 · only if needed

Work laptops and secure browsers

Done

Some workplaces open websites through a “browser isolation” service, such as Menlo Security. Signal may flash for a moment and then go black, even though the status panel says it's working. Two settings fix it.

  1. Open your address with this ending added: https://signal.example.com/?offscreen_worker=false. Bookmark it.
  2. Open the settings panel on the left edge of the Signal page (a small tab or drawer that slides out).
  3. In its video settings, change Encoder to JPEG. The browser remembers this.
What you should seeSignal stays visible instead of turning black.
Stuck? Common fixes
  • Still black: close every other tab with your Signal address open, then reload the bookmarked address.
  • The JPEG setting resets: the work browser may clear its storage each day. Set it again after opening the bookmark.
  • Your workplace blocks the site: follow your employer's rules. This guide doesn't get around work security policies.

Everyday use

You'll rarely need these. Run them from the project folder. In a new window, go to the folder first:

cd ~/signal-web-gate
cd "$HOME\signal-web-gate"
To…Run
See if everything is runningdocker compose ps
All three should say Up; the gate should say healthy.
See the tunnel's recent messagesdocker compose logs --tail 30 signal-tunnel
See the gate's recent messagesdocker compose logs --tail 30 signal-gate
Restart everythingdocker compose restart
Pause it (Signal is kept)docker compose stop
Start it againdocker compose start

You can also see the three containers in Docker Desktop under Containers → signal-web-gate, with start and stop buttons.

Change the password

This also signs out every browser, so use it if you think someone saw your password.

cd ~/signal-web-gate && bash scripts/setup.sh password
cd "$HOME\signal-web-gate"
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -ResetPassword

To change who can sign in, edit the policy in Cloudflare (step 5), then run the setup helper again, answer n to “Keep these settings?”, and enter the same emails.

Keep it updated

Check for a new version of this project every month or so. Your linked Signal stays in place.

If you used Git (option B)

cd ~/signal-web-gate && git pull && docker compose up -d --build
cd "$HOME\signal-web-gate"
git pull
docker compose up -d --build

If you used the ZIP (option A)

  1. Download the ZIP again from step 2 and unzip it. Don't overwrite your folder.
  2. Move your .env file and your secrets folder from the old signal-web-gate folder into the new one. (On a Mac, press ⌘ + Shift + . in Finder to show the hidden .env file.)
  3. Rename the old folder to signal-web-gate-old and the new one to signal-web-gate.
  4. Run the update: 
    cd ~/signal-web-gate && docker compose up -d --build
    cd "$HOME\signal-web-gate"
docker compose up -d --build
  5. Once it works, delete signal-web-gate-old.

Also keep Docker Desktop updated when it offers an update, and keep your computer's system updates on.

Stop or uninstall

Stop it for now (keeps your linked Signal)

cd ~/signal-web-gate && docker compose down
cd "$HOME\signal-web-gate"
docker compose down

To start it again later, run the setup helper again (step 7).

Remove it completely

This deletes the Signal copy on this computerYour phone and other devices keep all their messages.
  1. Delete the containers and the stored Signal data: 
    cd ~/signal-web-gate && docker compose down -v && docker image rm signal-web-gate:local
    cd "$HOME\signal-web-gate"
docker compose down -v
docker image rm signal-web-gate:local
  2. On your phone: Signal → Settings → Linked devices → tap this device → Unlink.
  3. In Cloudflare: delete the tunnel (Networking → Tunnels) and the Signal application (Zero Trust → Access controls → Applications).
  4. Delete the signal-web-gate folder.
  5. Optional: uninstall Docker Desktop like any other app.

Reference

Stay safe

  • Don't open ports on your home router. The tunnel doesn't need any, and the setup doesn't publish any ports on your computer either.
  • Keep Cloudflare Access on. Never delete or loosen the Signal Access application while this is running. Allow only specific email addresses.
  • Never share the .env file or the secrets folder. Don't email them, upload them, or put the folder in iCloud, OneDrive, Dropbox or a GitHub repo.
  • Use a unique gate password that's 12 characters or longer, and store it in a password manager.
  • Protect the computer: a login password, automatic screen lock, disk encryption, and system updates.
  • If something seems wrong (an unknown device in Signal's linked devices, or a sign-in you didn't make): unlink the device from your phone, change the password, and make a new tunnel token in Cloudflare.
  • Signal Desktop on this computer holds your messages. Cloudflare can see the traffic between your browser and your computer, because it handles the secure connection.

Glossary

Docker / container
An app that runs programs in sealed boxes, so they don't change the rest of your computer.
Terminal / PowerShell
A window where you type or paste commands. Terminal is on Macs; PowerShell is on Windows.
Domain
A web address you own, like yourname.com. signal.yourname.com is a sub-address of it.
Cloudflare Access / Zero Trust
Cloudflare's sign-in check, which emails you a code before anyone can see your page.
Tunnel / token
The tunnel is a private, outgoing connection from your computer to Cloudflare. The token is its secret key.
AUD tag
An ID Cloudflare gives your Access application. The gate checks it to make sure sign-ins are for your page.
Gate
The dark password page that comes after Cloudflare's sign-in.
.env and secrets
Files the setup helper creates in the project folder with your settings and keys. Keep them private.
